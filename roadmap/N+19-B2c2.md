## The shape change (65.2 raw-style → 65.3 composition · supersedes)

A descriptor was a **theme thunk emitting raw RN style**; it is now **pure data** — a composition of the
five disjoint primitive namespaces (`stack · box · typography · palette · interactive` · 65.3 §6) in
**semantic names** the platform-native engine resolves (factory on RN · CSS on web · 65.1). Behaviour
(`Pressable` / press transition / focus / a11y) is the factory's, never data ([decision 65](../decisionlog.md) ·
"behaviour ≠ data").

```ts
// BEFORE (65.2)                              AFTER (65.3 §7)
(theme) => ({ variants, compoundVariants? })  { structure: { anatomy, base }, variants? }
```

Dropped from the contract: the `(theme) =>` thunk · `ViewStyle & { $parts }` · `compoundVariants` ·
`Surface`/`Theme` · the `react-native` import. The emitted schema now imports **only** `./tokens`.

### Schema (`pipeline/descriptors/schema.ts`)
- **Leaf vocabularies** reuse the emitted scales ([decision 48](../decisionlog.md)): `SizeLeaf =
  keyof typeof size` (box sizing) · `TypeKey` (typography) · `SpaceLeaf` = the curated 5-leaf padding/gap
  subset (the Stack/Box dispatch) · `RadiusLeaf`.
- **The five namespaces** mirror the live primitives: `StackNS` (stack.css · `fill` enum · 60.1) · `BoxNS`
  (geometry only · no colour · [42.1](../decisionlog.md)/[60.1](../decisionlog.md)/65.3 §6) · `TypographyNS`
  (`size: TypeKey` · font only · 54/55 · 64) · `PaletteNS` (`{variant,accent,muted,chrome}` · mirrors the
  RN resolver) · `InteractiveNS` (`{pressColor,pressScale,disabledOpacity}` · the B2c·1 channels).
- **Per-part base** — `PartMap = Partial<Record<Part, NS>>` serves BOTH `structure.base` and each variant
  value (uniform shape), so a PART's invariant base (the Topbar content-pivot's `stack{fill}`) has a home
  (root-only base couldn't hold it). `PartAnatomy = { el, open?, parts? }`.
- `Descriptor<A> = { structure: { anatomy, base? }, variants? }` — pure data.

### Emitter (`pipeline/parsers/descriptors.js`)
Derives the composition form from the two sources (decision 48 · derive-don't-author), per the B1.5 §3
CSS→composition table: `background/color → palette` · `min-height/padding/radius → box` · `font →
typography` · `flex/align/justify/gap/fill → stack` · the `pressed/scale/opacity/affordance` → the derived
`interactive` opt-in. Every scale/surface VALUE is read + **validated** (the variant bg/fg/pressedBg ≡ the
surface funnel · geometry ≡ its scale · press-scale/disabled ≡ the interaction baseline · [decision 45](../decisionlog.md)),
then emitted as its SEMANTIC name. The Topbar host padding resolves through its LOCAL `--_inset-*` vars
([decision 46.1](../decisionlog.md)). The pressed/scale/disabled **collapse** to `interactive{pressColor,
pressScale,disabledOpacity}` on `base.root` (Button) — **no `compoundVariants`**; IconAvatar/Topbar are static.

## The three descriptors (match `docs/composition-model.md` §8 exactly)
- **composition-button** — `structure.base.root`: `stack{row,center,center}` + `interactive{pressColor,
  pressScale,disabledOpacity}`; `variants.variant.<v> → root.palette{variant}` (the label fg drops out — it
  follows by scope · F-BOX-FG-1 · the factory threads role-fg next); `variants.size.<s> →
  root.box{minHeight,paddingX,radius}` + `label.typography{size}` (sm→smEm, md/lg→mdEm · 55; lg→radius.md,
  md/sm→radius.sm · 41). No compounds.
- **icon-avatar** — static: `base.root` `stack{center,center}` + `box{width:lg,height:lg,radius:full}`;
  `variants.variant` → `root.palette{variant}` incl. `subtle`. No interactive.
- **topbar** — open: `base.root` `stack{row,center,gap:sm}` + `box{height:lg,paddingStart:lg,paddingEnd:lg}`
  + `palette{chrome:'canvas'}`; `base.content` `stack{fill:'grow-shrink'}` (the pivot · `flex:1 1 auto` is
  anatomy); `variants.center.true → content.stack{center,center}`.

## Paper-validated — the schema expresses the partial interactive profiles (the B3 freeze won't trap us)
`interactive` is three independent optional booleans, so any subset is expressible. Confirmed against the
live surfaces already on main (even though only the three are re-emitted):

| Surface | Profile | Schema |
|---|---|---|
| Button | scale + colour + disabled | `{ pressColor, pressScale, disabledOpacity }` |
| list-interactive-item ([decision 52](../decisionlog.md)) | colour only (no scale) | `{ pressColor }` |
| tab-bar ([decision 56](../decisionlog.md)) | scale only (no bg swap) | `{ pressScale }` |
| switch ([decision 44](../decisionlog.md) + [45](../decisionlog.md)) | scale + disabled | `{ pressScale, disabledOpacity }` |

The Switch's bespoke 0.92 knob scale is a per-channel **value-override** → stays mapped-not-built
([decision 30](../decisionlog.md)), as do `palette.outline` · `box` maxWidth/border · the `onSolid.muted`
token · the pressed-fg-muted (each lands with its first real consumer · P11).
