# N+62 · THE INFRA EXIT — Slice 3 closes · `@nuri/spec` is data-only

The **single closing session** for the projection-model refactor ([decision 80](../decisionlog.md) ·
[`docs/projection-model.md`](../docs/projection-model.md)). It collapses what was scoped as **3b·2b·ii + 3c + 3d**
into **ONE** session — deliberately, because it is **mechanical** (relocation · rename · repoint · **zero behaviour
change**), and the 5 CI gates + the equivalence harnesses are the **completeness oracle**: anything mis-pointed turns a
gate red. The substance was already finished (the colour model is data-driven, the RN contract is 100% TS-sourced, spec
had zero `build/` dependency); this session only **moves generated output into the projection that owns it and renames
the fossil dirs** — so `@nuri/spec` becomes pure data. No values change.

## The three movements

### Movement A — the RN contract → `@nuri/rn/generated/` (committed)

The generated RN artifacts left `spec/build/` for a committed `generated/` dir in the RN projection (A/B = **committed**,
coordinator-ratified · the per-projection §35 diff-review gate survives):

- `git mv` `tokens.ts` · `token-paths.ts` · `interaction.ts` · `icons.ts` · `palette.ts` → `packages/rn/generated/`.
- The **codegen** ([`scripts/tokens-parser.js`](../scripts/tokens-parser.js)) writes these into `RN_GENERATED` instead
  of `spec/build/`.
- **[`rn/contract.ts`](../packages/rn/contract.ts)** imports them **locally** (`@nuri/spec/tokens` → `./generated/tokens`,
  etc.). The descriptors stay `@nuri/spec/descriptors/*` (DATA · source).
- **[`@nuri/doc`](../packages/doc/pipeline/build.js)** reads `tokens`/`palette` from rn (and `token-vars` from prototype)
  via the new **[`strip.js`](../packages/doc/pipeline/strip.js)`#loadDataFromPath`** (read-by-absolute-path · the
  descriptor-twin precedent). DAG stays acyclic: rn → spec; doc → rn + prototype + spec.
- The `@nuri/spec` export subpaths `./tokens ./token-paths ./interaction ./icons ./palette` were **dropped**.

### Movement B — the web output → `@nuri/prototype/generated/` (committed)

The web artifacts left `spec/` for the prototype projection (a `generated/` dir, separate from its hand-authored
`styles/<ns>.css` to avoid the `typography.css` name collision):

- `git mv` the token CSS (`tokens-primitive` · `tokens-semantic` · `shell` · `typography`) → `generated/styles/`, the 3
  descriptor `.js` twins → `generated/descriptors/`, the web icon registry (`lib/components/icon/icons.js`) →
  `generated/icons.js`, `token-vars.ts` → `generated/`, and `tokens.json` → `generated/`.
- Repointed: the 3 **recipes** + **`primitives/icon.js`** (`../../spec/build|lib/…` → `../generated/…`), **`factory.test.js`**,
  the 4 prototype **namespace tests** (token-CSS reads → `generated/styles/`), **`css-preview.js`** (reads
  `tokens-semantic.css` from its own `generated/styles/`), the **playground** HTML, **`doc/stage.mjs`** (stages
  `prototype/generated` · drops the spec stagings), and the doc `head_custom.html` / `__preview__.html` asset links.
- The `@nuri/spec` export subpath `./token-vars` was **dropped**.

**Judgment call (noted · not a blocker):** `tokens.json` (DTCG · build-only · **no package consumer** — only the
round-trip drift guard reads it) was relocated WITH the web output rather than **dropped**. Dropping it would orphan
`buildDtcg`/`readPrimitives` and lose the primitive round-trip guard; relocating it keeps the guard alive while spec
goes data-only. It is the DTCG/Style-Dictionary interchange artifact — naturally grouped with the non-RN generated
output.

### Movement C — rename to the data-only layout + purge

With `build/` and `styles/` emptied, `@nuri/spec` became pure data:

- `pipeline/{dimensions,colours,typography}.ts` → **`tokens/`**
- `pipeline/{resolve-map,palette-surface,interactive-effects,typography-axis,property-spelling,interaction}.ts` →
  **`axes/`** (interaction landed in `axes/` · the cross-component baseline constant SoT)
- `pipeline/descriptors/{composition-button,icon-avatar,topbar,schema}.ts` → **`components/`**
- **Deleted** `build/` · `styles/` · `lib/` (the `scope/` tombstone) · the 2 `pipeline/*-computed-check.html`. **Kept**
  `icons/` (the SVG SoT).
- The exports map repoints the descriptor subpaths → `components/`, the axis/SoT subpaths → `axes/`/`tokens/` (the
  subpath NAMES stay stable — only the `build/`/`pipeline/` targets moved). Internal relative imports fixed:
  `axes/resolve-map.ts` (`./descriptors/schema` → `../components/schema`) and `components/schema.ts`'s type-query
  imports (`../dimensions|colours|typography` → `../tokens/…`).
- The codegen's input paths updated (`pipeline/…` → `tokens/`/`axes/`/`components/`).

## Gate change

The `spec` job's freshness step now diffs the **new generated homes**:
`git diff --exit-code packages/rn/generated packages/prototype/generated` (spec has nothing generated to diff). All 5
job names unchanged (required checks). Under A/B = committed there is no build-order issue — the rn/doc/expo jobs use the
committed files.

The equivalence harnesses in root `scripts/*.test.js` were repointed to the new homes (the token CSS reads → prototype
`generated/styles/`; the RN-artifact reads → rn `generated/`; the SoT reads → spec `tokens/`/`axes/`/`components/`). Two
harness fixes were substantive: (1) the **primitive-reachability** walk now scans **both** `prototype/generated` (the
token CSS that consumes the colour primitives) **and** spec (the axis SoTs — e.g. `interactive-effects.ts` authors the
`var(--nuri-interaction-*)` references, exactly as it did pre-move when both lived under spec); (2) **Guard F**'s frozen
`leafForms` pins re-homed onto the new SoT import paths (the schema SHAPE is unchanged — only the moved path).
