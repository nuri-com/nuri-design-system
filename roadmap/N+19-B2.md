### The model in one screen (detail → composition-model.md §6–9)
A **recipe = 100% composition of five disjoint namespaces, zero raw style**:
- `stack` (flexbox: direction/gap/align/justify/wrap/fill) · `box` (the element's own box: sizing ·
  padding · radii · border-w/style · transform · opacity — **no colour**) · `typography` (font · no
  colour) · `palette` (**all** colour from `{variant, accent, muted, interactive}` → bg/fg/fgMuted/
  border/pressed) · **`interactive`** (a cross-cutting *flag*, not a style).
- **Two layers** (decision 64): the **composition primitive** fixes *anatomy* + overridable defaults;
  the **recipe** *locks* the design. `Descriptor = { structure:{ anatomy, base }, variants }`.
- Colour flows by **scope** (F-BOX-FG-1) — text/icon inherit the role fg; a `variant` patch touches
  root only. CSS stays SoT (the 65.1 bootstrap · §9 source-flip deferred).

### The B2 build (decomposed · what to plan + brief)
1. **B2a · primitive extensions** — `box` sizing (`width`/`height`/`minHeight`) + `transform` +
   `opacity` (**geometry only · no colour**) · `stack` `fill` → `grow|grow-shrink` enum. **Web + RN
   mirrors.** Foundational, low-risk (exact list · report §2). Disjoint from B2b.
2. **B2b · the palette engine** — `{variant, accent, muted, interactive} → {bg, fg, fgMuted, border,
   pressed}`, owning **all** colour incl. the **chrome slot** (`canvas|subtle|strong`). Web (**no
   primitive today — the biggest, most novel piece**) + RN (fg delivered via the **surface-context** ·
   no `currentColor` · F-BOX-FG-1). **Likely a short design pass first** (the web realization is open).
   Folds in scoping the **decision-42 `box.background` deprecation** (live consumer: Tabs).
3. **B2c · re-emit + factory + rewire** — re-emit the descriptors in **composition form** (supersedes
   B1's raw-style) · draft the **factory** (typecheck-only · **one merged painting node per anatomy
   node**, NOT nested wrappers · report §4.2 · font on the **label part** · `interactive` wires
   Pressable/cursor/transition/`:active`/disabled/focus) · **rewire the mirrors to derive** + prove
   structural equivalence. Consumes B2a + B2b.
4. **B3 · freeze** — the schema-shape guard (the frozen contract). Then **Digital-cash** = the first
   post-freeze consumer (decision 65).
- **Boundary (hard · decision 65):** the factory/engine is the **Expo team's**; we *draft* it in-repo
