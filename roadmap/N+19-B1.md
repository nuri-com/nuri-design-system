## 3 · The emitter (ship item 4)

[`pipeline/parsers/descriptors.js`](../pipeline/parsers/descriptors.js) — a new Slice 6 in the
orchestrator. Reads **BOTH** sources (decision 65 guardrail · emit FROM, never re-author):

- **Mapping half** — the `@layer` CSS (`lib/components/<name>/<name>.css`). Realizes the spike's
  `derive-button.ts`: resolves each variant/size/compound value through the component-token alias
  (Button) or the direct semantic var (IconAvatar/Topbar), and **VALIDATES** colours against the
  surface funnel (resolver-model §11) — a drift (a variant pointing at the wrong chrome/accent token)
  throws at build (the 65.1 bootstrap, enforced). Geometry → `theme.{size,space,radius}.*`; the size
  font block → the `typeStep` key (decision 54/55); press-scale / disabled-opacity →
  `theme.interaction.*`.
- **Structure half** — the page `data-part` anatomy (`pages/components/<name>.html` · decision 24.1).
  `pageParts()` reads the declared parts; the emitter asserts each routed part (`label`/`icon`/
  `content`) is declared (a renamed/removed part throws). The property→part routing is the deriver's
  tuned engine-knowledge (cf. derive-button.ts's lookup tables): colour/typeStep → the text part,
  bg/geometry → root, center alignment → the content pivot.

Output is **deterministic** (canonical axis ordering) and **additive** — written to a separate
`build/descriptors/` dir so `build/components/*.ts` + their counts (the docs-drift Guards B/C) are
untouched.

## 5 · `button.html` gains the `label` part (the structure source) — operator note

The spike's Button descriptor places label colour + type on **`$parts.label`**, but `button.html`
declared only **`root`** (1 part) — it described the **web's single `<button>` node**, where the
label is a bare text node. IconAvatar (`root`+`icon`) and Topbar (`content`) already declare their
non-root parts; Button alone hid its `label`. Per the decision-65 structure-emit ("the layout
primitives now get a structure emit they previously refused") + the spike's FINDINGS recommendation
#4 ("sequence the structure-emit alongside the mapping-emit · a CSS-only bootstrap underfills the
contract"), **`button.html` now declares `root` + `label`** (2 parts), faithful to the cross-platform
reality (RN renders the label as a distinct `<Text>` routed through Typography · decision 64, as
`button.tsx` already does). This is the page becoming the genuine structure source (one source, two
readers), and it makes the drift guard uniform (a renamed/removed part breaks the build + test for
all three). **Flagged for the operator** at the checkpoint — confirm this is the intended structure
emit, or redirect.
