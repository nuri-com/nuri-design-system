# Session N+8 · List family REFACTOR · primitive/interactive/recipe split · first recipe (nav-item)

**Status**: closed (2026-05-30)
**Type**: component-surface REFACTOR session (re-cuts the N+7 List
capstone along three axes · adds the system's FIRST recipe · flips the
family from skip-emit to EMIT · one new semantic token)

## Outcome

Refactored the List family that [N+7](./N+7.md) assembled, along three
axes, and minted the system's **first recipe**:

1. **Interactivity moves OUT of the `list-item` primitive into a
   declarative WRAPPER.** `list-item` reverts to **purely
   presentational** (`role="listitem"`, no `interactive` attr, no
   overlay, no keyboard). The new
   [`<nuri-list-interactive-item>`](../lib/components/list-interactive-item/)
   WRAPS the row in a `role="button"` action box — **the content IS the
   button's accessible name**, read once. This is the **structural a11y
   fix** for N+7's double-read (the overlay carried a copied `aria-label`
   *and* contained the same visible text).

2. **The first RECIPE — [`<nuri-nav-item>`](../lib/components/nav-item/)**
   — a named composition `list-interactive-item ∘ list-item ∘
   auto-filled caret`, built by cloning a native `<template>` (NOT
   lit-html / JSX / imperative DOM). Skip-emit (empty `@layer tokens`):
   it owns no new style decision, only an arrangement of primitives that
   already own their tokens. Host is `display: contents`.

3. **The family's FIXED style values flip from skip-emit to EMIT** so
   web↔RN parity is machine-checked. `list`, `list-item`, and
   `list-interactive-item` now write `build/components/*.ts`; the recipe
   (`nav-item`) and the bare layout primitives stay skip-emit.

**Press treatment resolved**: the A/B `scale` experiment was **removed**
— the pressed wash is the new **`chrome.bgSubtleXFade`** semantic token,
a horizontal gradient that holds a **centred plateau** (doubled stop)
and dissolves at both edges.

## Decision locked

- **[Decision 52](../decisionlog.md#52-list-family-refactor--primitiveinteractiverecipe-split--wrap-not-overlay-a11y-fix--emit-fixed-values--first-recipe-nav-item--n8) ·
  List family REFACTOR · WRAP-not-overlay · EMIT · first recipe.**
  (a) **a11y is STRUCTURAL — WRAP, not overlay**: the action box wraps
  the content so the content is the button's name (no copied label, no
  double-read); host `listitem`, inner row demoted to `presentation`.
  (b) **Full-bleed by NESTING + NO inline padding**: the wash reaches the
  edges because the box wraps the whole row; content sits flush with
  full-width Separators; the container owns the horizontal inset.
  (c) **EMIT, not skip-emit** for fixed values — the skip-emit-vs-EMIT
  line is "does the element bake a fixed style decision (EMIT) or merely
  dispatch a consumer-supplied one (skip-emit)?".
  (d) **First recipe = composition, not variant**, via `<template>`
  clone; optional `<nuri-list-item-leading>` is hoisted into the composed
  `list-item` (positioned by element type · decision 51).
  (e) **Docs section-per-recipe**: List becomes a nav section with Base +
  Navigation Item sub-pages.

## Ship list

1. **[`lib/components/list-item/`](../lib/components/list-item/)** ·
   reverted to presentational — `role="listitem"` only, no interactivity.
   `list-item.css` EMITs `paddingBlock` · `gap` (both `space.md`); the
   row carries **no inline padding** (content flush with full-width
   Separators). **Trailing right-pin**: `nuri-list-item-trailing {
   margin-inline-start: auto }` pins the trailing book-end to the row end
   even when content is a **bare text node** (which, being an anonymous
   flex item, never matches the `flex:1` element selector and so wouldn't
   push trailing over).

2. **[`lib/components/list-interactive-item/`](../lib/components/list-interactive-item/)**
   (new) · the declarative WRAPPER. EMITs `wash` (`transparent`) ·
   `washPressed` (`chrome.bgSubtleXFade`) · `radius` (`radius.sm`). Wraps
   the row in `<div role="button" tabindex="0">`; Enter on keydown, Space
   on keyup; fires a bubbling `press` CustomEvent (nav-agnostic).

3. **[`lib/components/list/`](../lib/components/list/)** · density flips
   to EMIT: `densitySmMinHeight` / `densityMdMinHeight` /
   `densityLgMinHeight` (`size.{xl,2xl,3xl}`) + `gap` (`space.xs`).

4. **[`lib/components/nav-item/`](../lib/components/nav-item/)** (new ·
   the first recipe) · skip-emit. `nav-item.js` clones a `<template>` and
   distributes authored children: a `<nuri-list-item-leading>` is hoisted
   into the composed `list-item`; everything else goes to the
   `.nuri-type-md--em` label span; the caret is auto-filled in the
   trailing. Caret muted via trailing `color: var(--nuri-border-strong)`

5. **[`styles/tokens-semantic.css`](../styles/tokens-semantic.css)** · new

   the primitive colour directly so the pipeline resolves the embedded
   ref(s) to a literal hex with no `--nuri-` leak.

6. **[`pipeline/tokens-parser.js`](../pipeline/tokens-parser.js)** ·

## Frictions

- **F-LISTITEM-ROLE-1 / F-FOCUS-1 / R1** · carry over from N+7 unchanged
  (RN has no `listitem` role; no focus-ring analogue; the family is
  parity-by-behaviour, not parity-by-DOM).
- **Gradient press wash on RN (new)** · `chrome.bgSubtleXFade` resolves to
  a CSS `linear-gradient(...)` string; a flat `backgroundColor` cannot
  render a gradient in core RN (would need `LinearGradient`). Tracked in
  [`FRICTIONS.md`](../docs/migration-tests/button-matrix/FRICTIONS.md).
