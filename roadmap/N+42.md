## The frame — the A3 pattern, applied to docs

A3 ([N+41](./N+41-prototype-carve.md)) moved the web mechanism + its CSS-gen out of `spec`; each
library owns the emitter for its own surface and reads `spec`'s DATA ([§5](./convergence.md)). A4 does
the same for documentation: the descriptor doc-gen MOVES out of `spec`'s pipeline into `@nuri/doc`, and
**re-sources onto `spec`'s DATA exports** instead of the pipeline classifier. The boundary it locks:
**`@nuri/spec` = pure data + schema; transforming data → Markdown is `@nuri/doc`'s job.** The proof is a
byte-identical Markdown gate ([N+40](./N+40.md) discipline — same bytes, different reader).

## The byte-identical gate (the proof the boundary is faithful)

The re-source is behaviour-preserving BY CONSTRUCTION: the px scales re-add the unit the pipeline strips;
the colour hex comes from the same resolved cross-product `tokens.ts` emits (chrome accent-invariant →
`chrome.light` ≡ `resolved[var][neutral][light]`); the var comes from the same `classifiedGroups`
`token-vars.ts` emits. So `git mv build/docs/*.md → generated/components/` (content preserved) then
`npm run build -w @nuri/doc` re-emits the 3 pages **byte-identical** — `git diff --exit-code generated/`
clean. The generated header (`emitter: pipeline/parsers/docs.js · re-emit: npm run build -w @nuri/spec`) is
kept VERBATIM to satisfy the literal byte-identity gate (a known cosmetic staleness — see Known below).

## The cross-package mechanism (the principled split · mirrors A3)

- **Declared data (`tokens` · `token-vars` · `palette`)** → resolved via the `@nuri/spec` **exports map**
  (`import.meta.resolve` · honours `exports`) + the brace-aware TS-strip loader (`.ts`-in-node).
- **The descriptor twins (`.js`)** → cross-package **relative** paths (`../../spec/build/descriptors/<n>.js`)
  — the build-free precedent (@nuri/prototype's recipes import the same).
- DAG: **`doc → prototype → spec`**. `doc`'s BUILD reads `spec` only (the data + the twins); `prototype` is
  consumed at RUNTIME (the staged site · `stage.mjs`), not in the build.
