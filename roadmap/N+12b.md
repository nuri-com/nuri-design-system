## Outcome

The 1961-line monolith

shared scaffolding relocated to `_shared.tsx`; the only deltas are the three
pre-existing drifts logged below (none fixed inline — each needs a design
decision, so none was silently expanded into).

  `build/*` re-exports (tokens, component tokens, icon registry, `SvgXml` shim),
  `resolveToken` + `RuntimeTokens`, `AccentContext` / `ThemeContext` +
  `AccentProvider`, `SpaceLeaf`, `typeStyle` + `TypeKey`, `useRuntimeTokens`.
- **One `<component>.tsx` per component** · 18 mirrors (see table).
- **`app.tsx`** · the demo composition (rows A–L, the stateful demo wrappers, the
  page shell, the demo-local StyleSheet). `export default App`.
- **`index.tsx`** · retired to a thin `export { default } from './app'` so the
  old import path still resolves.
- **`tsconfig.json`** · `include` `"index.tsx"` → `"*.tsx"` (covers every new
  file) + added `build/components/tab-bar.ts` (was transitively pulled before;
  now explicit). Dir name + tsconfig path UNCHANGED (the CI gate is stable).

## Drift logged (needs a decision — NOT fixed here)

- **D1 · Box is missing the web `background` + `radius` enums.** `box.js` observes
  `background` (`canvas` / `subtle` / `strong` / `accent-solid` / `accent-subtle`)
  and `radius` (`sm` / `md` / `lg` / `full`); the RN Box mirror exposes only the
  layout props (padding* / fill). Adding them makes Box a context-aware surface
  consumer (resolves chrome/accent + radius at render). Faithful to the web API,
  but it is a new prop surface + a token-resolution path, not a mechanical lift —
  so logged. (Comment block in `box.tsx`.)
- **D2 · Button is missing the web `size` prop.** `button.js` observes
  `size` (`sm` / `md` / `lg`) and `build/components/button.ts` emits the per-size
  geometry set (minHeight / paddingX / radius) AND couples the label type per size
  (decision 55). The RN mirror is md-locked. Adding `size` means dereferencing the
  emitted per-size TokenPaths inline + switching the label `typeStyle` key — a real
  feature, logged. (Comment block in `button.tsx`.)
- **D3 · Tab is missing the web `disabled` prop.** `tabs.js` `observedAttributes`
  includes `disabled` (a non-selectable option · muted + `aria-disabled`). The RN
  Tab mirror has no `disabled`. Faithful add = non-pressable + muted styling +
  `accessibilityState.disabled`; logged rather than silently added. (Comment block
  in `tabs.tsx`.)

## Note (value-neutral · not a behaviour drift)

- **D4 · IconButton token sourcing.** Build emits a dedicated
  `build/components/icon-button.ts` (`iconButton.size = 'size.lg'`,
  `.radius = 'radius.full'` + its own variant tokens). The mirror intentionally
  reuses the shared `button.*` variant funnel (the decision 39/40 funnel the web
  `.nuri-icon-button` shares with `.nuri-button`) and HARDCODES `size.lg` /
  `radius.full` for geometry rather than dereferencing the emitted
  `iconButton.size` / `.radius`. Values are identical; whether to dereference the
  emitted tokens (the decision 52 EMIT-not-hardcode principle) is an OPEN,
  value-neutral cleanup. (Comment block in `icon-button.tsx`.)
