Three workstreams, all confined to `docs/migration-tests/*` + `docs/RISKS.md`

carried the two per-dimension contexts decision 27 had REJECTED.

### A · NuriThemeContext lands (closes F-SCOPE-1 · decision 62)

- **`_shared.tsx`** · the two contexts (`AccentContext` + `ThemeContext` +
  `AccentProvider`) are replaced by a SINGLE `NuriThemeContext` carrying
  `{ mode, accent }` (defaults `mode:'light'`, `accent:'lilac'`) + a composite
  `NuriScope` provider with merge-on-override
  (`<NuriThemeContext.Provider value={{ ...ambient, ...overrides }}>`).
- **Every mirror** consumes one `useContext(NuriThemeContext)`; `theme` →
  `mode` throughout. Tier-2 self-scope keeps prop-wins via an inline merge
  (`accentProp ?? ambientAccent`).
- **`app.tsx`** demos use `<NuriScope>`; the Tier-3 demo is
  `<NuriScope accent="neutral">` (accent flips, mode inherits — the
  merge-on-override exercise).
- Two live dimensions = the **n=1 confirmation** decision 27 awaited.
  `density` / `neutral` stay RESERVED (not context entries · P11) until their
  web tokens ship; `font` is web-only (amendment 27.1) and never migrates.
- **Decision 62** recorded; **F-SCOPE-1 → CLOSED** in RISKS R1; the scope page
  + `scope/README.md` + impl-guide now describe EXACTLY what the examples do
  (zero residual spec↔example gap).

### B · D1–D4 faithful-to-web drift adds (honor existing decisions · no new design)

- **D1 · Box** gains `background` (5-enum) + `radius` (4-enum) props
  (decision 42) — resolves chrome/accent at render via `resolveToken`.
  Delta logged: **F-BOX-FG-1** (the web `accent-solid` also sets the
  foreground colour; the RN Box surface doesn't cascade text colour).
- **D2 · Button** gains the `size` prop (`lg`/`md`/`sm` · decision 41) —
  dereferences the emitted per-size geometry triples + couples the label type
  key to size (decision 55: sm→smEm, md/lg→mdEm).
- **D3 · Tab** gains `disabled` (decision 42/43) — non-pressable + muted +
  `accessibilityState.disabled`, reusing the shared
  `--nuri-interaction-disabled-opacity` primitive. Delta logged:
  **F-TAB-DISABLED-1**.
- **D4 · IconButton** now DEREFERENCES the emitted `icon-button.ts` geometry
  (`iconButton.size` / `.radius`) instead of hardcoding `size.lg` /
  `radius.full` (the value-neutral EMIT-not-hardcode cleanup N+12b logged).
  Values unchanged.
