# Session N+8.2 · Typography cleanup · eliminate `typography-stack-element` · `muted` on Typography

**Status**: closed (2026-05-31)
**Type**: structural cleanup (reverses the confusing half of
[decision 47](../decisionlog.md#47-typographystack-family--contextual-text-hierarchy-primitive--level-carried-by-the-element--n67) ·
no new component surface · no new tokens · one new boolean prop)

## Outcome

[Decision 47](../decisionlog.md#47-typographystack-family--contextual-text-hierarchy-primitive--level-carried-by-the-element--n67)
shipped TypographyStack as a **two-element compound**: a flex container
(`<nuri-typography-stack>`) holding `<nuri-typography-stack-element
level="1..5">` lines, where each `level` mapped a *contextual sub-scale*
to an existing `.nuri-type-*` utility **and** dispatched a chrome text
colour off `data-level` (1–4 → `text-primary`, 5 → `text-muted`). The
sub-scale was a second, parallel type vocabulary that only TypographyStack
spoke — it leaked contextual hierarchy into a context that already had the
absolute `size` vocabulary on `<nuri-typography>`, and it forced authors to
learn "level 2 means md-emphasis" instead of just writing the props.

N+8.2 collapses the compound to **one** element and pushes the colour
decision onto the primitive:

1. **`<nuri-typography-stack-element>` is eliminated.** Its class, its
   `data-level` colour dispatch, and the `LEVELS` / `TYPOGRAPHY_STACK_LEVELS`
   maps are removed (web JS + CSS, RN migration test). No
   `<nuri-typography-stack-element>` remains anywhere — static or RN.

2. **`<nuri-typography-stack>` survives** as the flex-rhythm container it
   always was: column default (`gap space.2xs`), `[direction="row"]` flips
   to `align-items:baseline` + `gap space.xs`. It now lays out plain
   `<nuri-typography>` children. Empty `@layer tokens` → **stays skip-emit**
   ([decision 37](../decisionlog.md#37-layout-primitives-consume-semantic-vocabulary-via-prop--no-component-token-aliasing--n62)).

3. **`<nuri-typography>` gains a `muted` boolean.** Present → text colour
   `var(--nuri-text-muted)`; absent → `currentColor` (primary). JS reflects
   `data-muted`; CSS owns the colour
   ([decision 42](../decisionlog.md#42-box-gains-background--radius-props--attribute-dispatch-surface-vocabulary--evidence-gated-promotion--n65)
   attribute-dispatch · JS reports state, CSS owns appearance). `size` +
   `emphasis` unchanged; Typography **stays skip-emit**.

4. **The 5-level scale is dropped — and deliberately NOT replaced by a
   guidance table.** An earlier draft kept the 1–5 table on
   `typography-stack.html` as *advice* (each former level → explicit
   Typography props). At the visual checkpoint the operator called it: a
   size/emphasis/muted-per-step doctrine is **invented advice** with no
   shipped consumer behind it ([P11](../pages/principles.html#p11-parsimony) ·
   [decision 30](../decisionlog.md#30-primitive-parsimony--no-speculative-additions--n571)),
   so the whole §5 "Hierarchy guidance" section was removed. The stack
   imposes no scale; the author composes `size` + `emphasis` + `muted` per
   line directly. A formal hierarchy doctrine is **deferred until the
   type-scale principles are documented** — it can then land grounded in
   principles rather than guesswork.

5. **Components compose `<nuri-typography>`**, not raw `.nuri-type-*`
   utilities: `<nuri-nav-item>`'s label and `list-base.html`'s anatomy row
   both swap to composed Typography lines. The anatomy's **leading
   icon-avatar is kept** (operator-confirmed).

## Decisions locked

- **[Decision 53](../decisionlog.md#53-typographystack--element-eliminated--muted-on-typography--n82)** ·
  TypographyStack `-element` eliminated · `muted` on Typography. Amends
  [decision 47](../decisionlog.md#47-typographystack-family--contextual-text-hierarchy-primitive--level-carried-by-the-element--n67):
  the rhythm container, its skip-emit status, and the column-`2xs` /
  row-`xs` gap values **stand**; the `-element`, the `level` sub-scale, the
  `data-level` colour dispatch, and `TYPOGRAPHY_STACK_LEVELS` are
  **superseded**. `muted` is a **boolean, not a `tone` enum** — no
  `tone="primary|muted|accent"` floodgate
  ([P11](../pages/principles.html#p11-parsimony) · the same restraint as
  Icon having no tone · [decision 38](../decisionlog.md#38-icon-component--phosphor-source--nuri-icon-name-nuri-facade--2-size--fill--registry-based-js-dispatch--n63)).
- Decision 47 gains a **supersede blockquote** at its head pointing at
  decision 53.

## Anti-scope (held)

- **No type-emit / reverse of [decision 34](../decisionlog.md#34-per-component-files--tokenpath-union--set-policy--pipeline-emit-shape--n603)** —
  RN type values stay hand-declared; that is **N+8.3**.
- **`muted` is a boolean, not a `tone` enum** — no
  `tone="primary|muted|accent"` (P11 floodgate).
- **Typography + TypographyStack stay skip-emit** — no new tokens, no
  per-component emit.
- **List / ListItem / InteractiveListItem / Separator / IconAvatar untouched**
  beyond nav-item's content line and the anatomy row.
- **The anatomy leading icon-avatar is kept** — only the typography element
  inside the row changed.
- **No `<nuri-typography-stack-element>` left anywhere** (static or RN).

## Frictions

- **R1 (web↔RN parity)** · carries over. The new `muted` boolean crosses
  cleanly (`data-muted` → a `muted` RN prop selecting `chrome[theme].textMuted`).
  RN has no `currentColor`, so the non-muted line uses `chrome[theme].textPrimary`
  as the documented analogue.
- No new friction codes minted.
