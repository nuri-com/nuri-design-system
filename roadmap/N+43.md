## The frame — the A4 pattern, applied to the axes

A4 ([N+42](./N+42.md)) stood up `@nuri/doc` + the **descriptor** doc family + locked the data→MD
boundary ([decision 75](../decisionlog.md)). A4b adds the **axis** family — an independent emitter
slotting into the same shell, nav, and helpers. The axes are the system's spine (the cascade's L3 ·
[decision 73](../decisionlog.md)'s **2 agnostic + 3 bespoke**), so they are the highest-value new
docs. Each axis SoT is clean typed data; the emitter walks it → a Markdown table, exactly as
`descriptor-ir.js → docs.js` does for components. Because the axes are bespoke, the docs are too —
**four shapes, one per SoT**, not one mould.

## What shipped

1. **The axis-IR builders** ([`packages/doc/pipeline/axis-ir.js`](../packages/doc/pipeline/axis-ir.js) ·
   NEW · the axis-family sibling of `descriptor-ir.js`). One pure builder per SoT shape →
   a structured IR:
   - **box / stack** ← `resolve-map.ts` (`BOX_FIELDS`/`STACK_FIELDS`) + `property-spelling.ts`
     (`PROPERTY_SPELLING`). Per input field: the input key, its **CSS** name (`registry[prop].css` →
     `padding-inline`), its **RN** name (`registry[prop].rn` → `paddingHorizontal`), and the
     value-SOURCE (the `via`: `scale` NAME / `keyword` map / `literal` passthrough / `flag` on-off).
     The mechanism-divergent `fill`/`expand` arm has NO registry entry → css=`flex`, rn=`—`, the
     per-value RN expansion in the Value column + a caption ([decision 73](../decisionlog.md) cl.2).
   - **palette** ← `palette-surface.ts` (`surface`). variant XOR chrome → bg/fg/pressed, each paint
     RESOLVED to a live `var()` swatch + role NAME + default-scope hex (the ONLY axis that resolves
     tokens · the absent channel → `—` · ghost's `transparent` → a bordered empty swatch).
   - **interactive** ← `interactive-effects.ts` (`effects`). Per effect: name · the assembled
     selector (`.nuri-interactive` + the attr gate + the pseudo-state · comma-joined) · the decls ·
     the gate (automatic vs the `data-*` opt-in, structurally derived). The **load-bearing order**
     (pressScale before disabledGuard · equal-specificity `transform`) surfaced as a data-derived note.
   - **typography** ← `typography-axis.ts` (`axis`). The `nuri-typography` WRAPPER dispatch (muted +
     align) — a real element, unlike palette/interactive's merged-node class. **Wrapper only** — the
     type SCALE (size/emphasis · `--nuri-type-*`) is a Foundations doc (A4c), scoped OUT.

   Plus the `AXIS_DOCS` manifest (source · nav_order · the SoT header path · the one-line lead ·
   the build thunk). @nuri/doc owns WHICH axes it documents + their nav order (the 2 agnostic, then
   the 3 bespoke).

2. **The axis-page rendering** (in [`docs.js`](../packages/doc/pipeline/docs.js) · `emitAxisPage` +
   the 4 kind renderers). A pure function of (ir · the manifest's nav/src/lead) → the just-the-docs
   page. Reuses the component emitter's `swatch` helper + the `ATTR_SEP`/`NO_VALUE` cell idiom.
   The palette swatch resolver — **`makeRoleResolver`** — re-keys the N+22 colour resolver
   (`makeColorResolver`) by the L2 role NAME via a var-keyed reverse map over the SAME `token-vars`
   registry (the role `bg-strong` ≡ the var `--nuri-bg-strong`), NOT a hand re-derivation of spec's
   group/camel convention in doc (the N+42 boundary · the var spelling is spec's data).

3. **The provenance-header re-path** (the N+42 → A4b carry · discharged). The GENERATED header was
   extracted into a SHARED `genHeader(source)` helper (component + axis emitters), re-pathed to the
   @nuri/doc home: `emitter: packages/doc/pipeline/docs.js · re-emit: npm run build -w @nuri/doc`
   (was the stale pre-move `pipeline/parsers/docs.js · npm run build -w @nuri/spec`, kept verbatim
   through A4 to preserve THAT session's byte-identical proof). `source:` is now repo-relative +
   unambiguous (`packages/spec/build/descriptors/<name>.ts` · the SoT is a sibling package). All
   `.md` regenerated: the 3 component **BODIES stay byte-identical** — only the 2 header lines change
   (6 insertions / 6 deletions total); the 5 axis pages carry the correct header from birth.

4. **`build.js`** — split into `buildComponentDocs` (A4) + `buildAxisDocs` (A4b · loads the 5 SoTs +
   the role resolver · emits `generated/axes/{stack,box,palette,interactive,typography}.md`),
   `buildDocs` concatenates.

5. **`strip.js` — one-token extension** (`stripConstAnnotations` now matches **bare** `const NAME: T =`,
   not only `export const`). `resolve-map.ts` annotates its private `ALIGN`/`JUSTIFY`/`FILL` consts
   the same way as its exported tables; the prior `export const`-only regex left them un-stripped
   ("Missing initializer" on import). The fix is doc's depth-aware analogue of @nuri/prototype's
   bespoke `resolve-map` strip (`namespace-css.js#stripTypes`). The other 4 SoTs loaded unchanged.

6. **The Axes nav landing** ([`axes.md`](../packages/doc/axes.md) · `has_children: true` · the
   2-agnostic/3-bespoke description · the placeholder blockquote retired) + **`_config.yml`** (a
   `generated/axes` → `parent: Axes` front-matter DEFAULT · the byte-identical-nav trick the
   component pages use · injected at Jekyll time so the `.md` stay byte-identical).

7. **Guard G extended** ([`docs-drift.test.js`](../packages/doc/pipeline/docs-drift.test.js)) — a 2nd
   test: each `generated/axes/*.md` re-emits ≡ committed, from the SoT-built IR + the manifest, plus
   per-page contract pins (front-matter · the re-pathed header · the load-bearing cells: the box/stack
   spelling + the `fill` em-dash · the palette resolving swatch + the fg-only `subtle` em-dash · the

## The boundary held (the proof the re-source is faithful)

The axis IR is a pure function of the AUTHORED SoTs ([decision 67](../decisionlog.md) · read via
`strip.js`, NEVER spec's pipeline functions); the palette hex comes from the same `token-vars` +
`tokens` data the component swatches use (the role `bg-strong` resolves to the same `#f3f1e2` the
descriptor's `chrome.bgStrong` does). So the emit is deterministic (idempotent — two builds, identical
md5) and `npm run build -w @nuri/doc` re-emits every page byte-identical.
