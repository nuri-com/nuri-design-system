## The contract (operator-settled · built exactly as briefed)

One rule: **a palette surface resolves its complete pair — bg AND fg — explicitly.** No ambient, no
inheritance semantics, no scope sentinel, no React context. The engines apply both channels. At most
one of `variant` | `chrome` per node. The mapping is **accent×theme-GENERIC** (`accent.solid`, never
a concrete colour) — resolution happens in the engine (decision-34 indirection).

| input            | bg                  | fg                   | fgMuted                      | pressedBg              |
|------------------|---------------------|----------------------|------------------------------|------------------------|
| variant=solid    | accent.solid        | accent.onSolid       | (onSolid.muted · NOT BUILT)  | accent.solidPressed    |
| variant=soft     | chrome.bgStrong     | chrome.textPrimary   | chrome.textMuted             | chrome.bgPressed       |
| variant=ghost    | transparent (explicit literal · the ghostBg emit convention) | chrome.textPrimary | chrome.textMuted | chrome.bgSubtle |
| variant=subtle   | — (fg-only)         | chrome.borderStrong  | —                            | —                      |
| chrome=canvas    | chrome.bgCanvas     | chrome.textPrimary   | chrome.textMuted             | —                      |
| chrome=subtle    | chrome.bgSubtle     | chrome.textPrimary   | chrome.textMuted             | —                      |
| chrome=strong    | chrome.bgStrong     | chrome.textPrimary   | chrome.textMuted             | —                      |

`muted` stays delivered by Typography's existing `data-muted` dispatch (≙ the fgMuted column); no
node-level muted dispatch was added. RESERVED · mapped-not-built (decision 30): `'outline'` · the
`border` role · `onSolid.muted` — present in types/comments only, **no values emitted**.

## The guard (decision 48 · one source, two readers)

Realization: **author-in-emitter + cell-for-cell CSS assertion at build + the Guard-E drift test**
(the descriptors-SURFACE discipline, applied to the palette table). `derivePalette` THROWS — so
`npm run build` fails — on any contradiction between the contract wiring and the parsed CSS:

| cells | asserted against |
|---|---|
| variant solid/soft/ghost × bg/fg/pressedBg | `button.css` `@layer tokens` aliases (`--nuri-button-<v>-{bg,fg,bg-pressed}`) |
| variant subtle fg | `icon-avatar.css` `.nuri-icon-avatar--subtle` colour |
| chrome canvas bg/fg | `topbar.css`'s direct host `background`/`color` pair |
| every fgMuted | `typography.css` `nuri-typography[data-muted]` colour |
| **every** bg/fg cell | `palette.css`'s own dispatch rows (missing channel, wrong target, **or a stray rule** — e.g. an early pressed/muted dispatch — throws) |

docs-drift **Guard E** re-derives from the live CSS (so `npm test` fails on the same drift), asserts
the emit equals the committed `build/palette.ts` (stale/hand-edit), and pins the operator table
verbatim (`EXPECTED_PALETTE`) — a coordinated CSS+re-build change still fails until the pin is
deliberately updated. Six contradiction classes negative-tested in-memory (alias flip · palette.css
flip · stray rule · missing pair channel · topbar flip · muted repoint): all throw named errors.

**One derivation note (reported, per brief):** chrome **subtle/strong** have no live recipe pairing
in the CSS today (B1.5 §3's chrome row derives only `canvas` from topbar). Their **bg** cells tie
through the classifier by slot name (`--nuri-bg-<slot>` — a renamed leaf fails the emit) + their
literal decls in palette.css; their **fg** is the slot-uniform fg the topbar pair establishes
(asserted equal to canvas's). Box.css's `data-background` decls were deliberately NOT used as a
witness — that surface is U3's deprecation target (coupling the guard to it would create U3
friction). No cell contradicted the contract table; nothing was improvised.

## Handoff to B2c
The colour namespace is now real on all three surfaces: dispatch CSS (rest state), emitted mapping
(incl. `pressedBg`), resolver. B2c consumes them: the `interactive` flag wires the pressed dispatch

surface live (`chrome` slot ≙ canvas/subtle/strong; `accent-solid` ≙ variant=solid;
`accent-subtle`'s fate = U3's migration table).
