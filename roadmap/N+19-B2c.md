### What B2c reworks (the concrete current state — verified)
- **The schema is still 65.2 raw-style.** `build/descriptors/schema.ts` (source:
  `pipeline/descriptors/schema.ts`) is the CVA core — `variants`/`compoundVariants`, a `$parts` overlay,
  **bare `ViewStyle`/`TextStyle` patches** + one `typeStep` ref, as a `theme` thunk. The emitted
  descriptors (`composition-button.ts` · `icon-avatar.ts` · `topbar.ts`) carry **raw RN style**, e.g.
  Button: `{ backgroundColor: theme.surface.solid.bg, $parts:{ label:{ color: … } } }` ·
  `{ minHeight: theme.size.lg, paddingHorizontal: … }` · `compoundVariants:[{pressed:true, styles:{
  transform:[{scale: theme.interaction.pressScale}] }}, …]`.
- **65.3 supersedes this**: re-emit so each patch is a **namespace composition** — `palette:{variant}`
  (not `backgroundColor`) · `box:{minHeight,paddingX,radius}` (not raw) · `typography:{size}` on the
  label part · `interactive` as the flag (not raw `compoundVariants` transform/opacity). B1's pipeline /
  validated values / part-targeting carry forward; the **form** changes (the schema rework is the heart
  of B2c). Drift Guard D (`pipeline/docs-drift.test.js`) extends to the new form.
- **Two deferred channels to build first** (interactive's outputs · confirmed missing on `main`):

### Open design calls to resolve with the operator (before the heavy build)
- **The `interactive` flag — does it DERIVE its effects, or list them?** The palette already carries
  `pressedBg`, and the baseline carries `pressScale`/`disabledOpacity` (theme.interaction). So a recipe
  could just declare `interactive` and the **factory derives** pressed-bg (palette) + press-scale
  (→box.transform) + disabled-opacity (→box.opacity) + focus ring — vs the current explicit
  `compoundVariants`. Coordinator lean: **derive** (DRY · P11 · the data already exists; the flag is the
  trigger, §2/§4). This is the U1-deferred design — settle it first; it shapes both the channels (1) and
  the schema (2).
- **The re-emit descriptor shape** — confirm `Descriptor = { structure:{ anatomy, base }, variants:{
  axis:{ value:{ part: NS } } } }`; the **anatomy-vs-base** line (B1.5 §4.1: `base` mixes load-bearing
  vs overridable — moot for the closed recipe, matters for the open `composition-` layer · likely defer
  the marker).
- **Factory scope** — "draft typecheck-only" = how much it builds vs proves; how structural equivalence
  is asserted against the mirrors (typecheck + a structural test?).
- **Pressed/interactive web form** — palette `:active` gated on the merged node carrying an
  `interactive` flag (a `.nuri-interactive` class / `data-interactive`), so a static surface (Tabs
  chrome) never gets `:active` swaps.
