## What B3 freezes (and what it doesn't)

The cross-repo contract **is** the schema SHAPE ([decision 65](../decisionlog.md) · [65.1](../decisionlog.md) · the source-agnostic freeze). B2c·2 landed the descriptor in pure-data composition form; B3 makes that shape an **enforced** lock — the guard breaks if the shape drifts, so post-freeze changes must be deliberate + versioned.

**Locks** (the schema SHAPE · `pipeline/descriptors/schema.ts`):
- the five namespace **field vocabularies** — `StackNS` · `BoxNS` · `TypographyNS` · `PaletteNS` · `InteractiveNS` (each field name → its declared value type · the `?` optional marker included);
- the **leaf vocabs** — `SpaceLeaf` / `RadiusLeaf` member sets · `SizeLeaf` / `TypeKey` declaration forms (their members live in the tokens emit · governed by Guard C, not the shape freeze) · the `PaletteVariant` / `PaletteChrome` sub-vocabs;
- the **envelope** — `Part` · `El` · `NS` · `PartAnatomy` · `PartMap` · `Axes` · `Variants` · `Descriptor` ([65.3](../decisionlog.md) §7).

A field added / removed / renamed / **retyped**, or a union member moved, = a contract change = the guard breaks until the frozen pin is deliberately updated.

**Does NOT lock**: the per-component **AXES** (variant/size values · per-descriptor type params) nor the instance **VALUES** — those re-derive from live CSS and are kept faithful by **Guard D**. The freeze is the cross-repo TYPE contract; Guard D keeps the instances faithful. (A descriptor's `variant: ['solid','soft','ghost']` axis is an *instance* subset of the schema's `PaletteVariant = 'solid'|'soft'|'ghost'|'subtle'` vocabulary — distinct layers, no conflict.)

## The mechanism — (B) runtime structural pin · operator-confirmed

Two mechanisms were on the table at the checkpoint:

- **(A) compile-time type freeze** — a frozen reference type + `tsc` `AssertEqual<Live, Frozen>` assertions. Robust (catches even an unused-field addition) but arcane, duplicates the schema as a frozen mirror, and needs its own tsc gate wiring (button-matrix retires after the relocation · 65.5).
- **(B) runtime structural pin** — **chosen** — a guard (**Guard F**) in `pipeline/docs-drift.test.js` pinning a legible `FROZEN_SCHEMA` spec (namespaces → fields · the leaf/structural unions · the Descriptor envelope) and asserting the schema source declares exactly that. Matches the repo's pin-and-assert guard style (Guard D/E) · runs under the existing `npm test` gate · the frozen spec reads as the contract lock.

The operator confirmed **(B)** at the checkpoint; **(A)** stays the documented robustness fallback. B freezes the **source**; since Guard D already locks `build/descriptors/schema.ts ≡ emitSchemaTs(source)` ([decision 35](../decisionlog.md)), the freeze flows to `build/` transitively.

### Guard F (`pipeline/docs-drift.test.js`)
A brace-aware extractor (`typeRhs` / `typeFields` / `unionMembers` · `normType` canonicalizes spacing so the freeze catches CONTENT drift, not reformatting) reads each `export type` from the schema source and asserts it equals the pinned `FROZEN_SCHEMA`. Namespace fields + the envelope compare as field maps (key-order-insensitive); leaf/structural unions compare as sorted member sets; the two scale-derived leaves + the structural aliases (`PartMap` / `Axes` / `Variants`) compare by normalized declaration form. A missing/renamed type throws a legible message (drift, not a silent pass). The pin is the legible contract lock — it lists the frozen shape verbatim.

## The teeth — enforced, not honorary (the crux)
Perturbing the live schema source, Guard F breaks, then restores byte-identical:

| Perturbation | Result |
|---|---|
| ADD a namespace field (`StackNS.zIndex`) | `not ok 6 — namespace StackNS drifted …` ✓ |
| RENAME a field (`BoxNS.minHeight → minBlock`) | `not ok 6 — namespace BoxNS drifted …` ✓ |
| RETYPE a field (`gap?: SpaceLeaf → SizeLeaf`) | bites ✓ |
| ADD a leaf member (`PaletteVariant += 'outline'`) | bites ✓ |
| ADD an `El` member (`+= 'image'`) | bites ✓ |
| ADD a sixth namespace into `NS` | bites ✓ |

A freeze that doesn't break on drift is worthless; this one does. (Same posture as Guard D's teeth re-confirmation · B2c·2.)

## Versioning intent (the deliberate-change protocol · seed)
A post-freeze shape change is **deliberate + versioned**: update the `FROZEN_SCHEMA` pin in `pipeline/docs-drift.test.js` AND log it as a contract change in `decisionlog.md` (a 65 amendment). The freeze guard is the forcing function — the build stays red until the pin is consciously moved. The **full** version-negotiation machinery (a contract version field · consumer-side negotiation · deprecation windows) is **deferred to its first real consumer** — it ships with the first actual bump, not speculatively ([P11](../pages/principles.html#p11-parsimony) · [decision 30](../decisionlog.md#30-primitive-parsimony--no-speculative-additions--n571)). The first forcing case is Digital-cash's new anatomy, post-relocation (decision 65 · the post-freeze consumer).
