## The smell this fixes

The accent semantic layer was **role-major** — `accent[role][accentName][theme]` with the accent
names (`neutral` / `lilac`) baked into the type (`type AccentLeaf = { neutral; lilac }`). Adding an
accent (slice 2) meant **editing all six role entries + widening the type** — the wrong unit of
change. Reshaped to **accent-major**: each accent is **one object**, each role either a flat `string`
ref (theme-INVARIANT · the P4-frozen brand fill) or a `{ light, dark }` pair (theme-ADAPTING ·
`dark.ref ≠ light.ref`). The names are **out of the type** (`Record<string, Record<string, AccentRole>>`),
so slice 2 is "add one object," not six edits + a type change.
