## Findings (surfaced, not fixed — Guard F · the first-versioned-bump agenda)
1. **No default in the frozen descriptor.** The web binding-level default (`Button` = soft/md) is not
   in the contract. The generic factory falls back to the FIRST axis value (solid/sm) rather than
   inventing per-component knowledge. A **contract-level default** (a `default` marker per axis) would
   keep the RN API 1:1 with the web default without per-component code.
2. **Boolean axes are stringly-typed.** `Axes = Record<string,string>`, so Topbar's `center` is
   `'true'|'false'` → the generic prop is `center="true"`, not a boolean (the web is a boolean
   attribute). A **typed boolean-axis form** in the schema would restore `<Topbar center>`.

Together with R1's two findings (transversal interaction emit · `subtle` fg-only), the relocation has
surfaced a coherent first-versioned-bump agenda: **the contract is structurally sound but incomplete
for ergonomic 1:1 consumption** (default-per-axis · typed boolean axes · transversal interaction). The
likely forcing case is **Digital-cash** (the first post-freeze consumer · 65.6 · P11).
