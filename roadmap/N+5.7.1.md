## Why N+5.7.1 not folded into N+5.8

Two reasons:

1. **Domain separation.** N+5.8 is technical work (cream default
   parameterization · CLI flag · build parameter · oracle
   re-derivation in `build/tokens-parser.test.js`). N+5.7.1 is
   governance / philosophy. Bundling mixes mental models; a single
   working agent per domain keeps focus.
2. **Sequence value.** Parsimony lock IN PLACE before N+5.8 means
   the N+5.8 agent inherits the discipline. Cream re-derivation
   is precisely the surface where speculative additions could
   sneak in ("while I'm rewriting `tokens.ts`, let me add this
   convenience…"). The new FIXED anti-goal default in
   `prompts/working-session.md` plus the per-skill cascade
   defends the next session by construction.

X.Y.Z numbering: N+5.7.1 is the first sub-decimal in the project
(precedent: N+3.5, N+5.5, N+5.6 were X.5 / X.6 — `.5` / `.6` —
two-digit). N+5.7.1 reads as "derivative of N+5.7's findings,
single thrust, distinct from N+5.7's scope". Justified because
N+5.7 closed cleanly and this is a downstream governance lock,
not a continuation.
