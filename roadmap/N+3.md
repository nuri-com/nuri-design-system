# Session N+3 · Philosophy alignment + skill router + page-elimination + closeout audit

**Status**: closed
**Type**: main

## Outcome

Pivoted mid-session after the philosophy brainstorm. The original
plan ("agent-first refactor" of `home.html` + `colour.html`) was
replaced by **deletion** of both pages per
[decision 23](../decisionlog.md#23-entry-pages-eliminated--n3) —
once the philosophy locked, prose-essay entry pages had no consumer
to serve. Decisions 21–25 codified. Risk register created.

## Ship list

1. **Risk register created** ([`docs/RISKS.md`](../docs/RISKS.md)) — 6 risks
   ordered by mitigation leverage. R1 (web↔RN behavioural parity) ·
   R2 (pipeline schema validated late) · R3 (no verification beyond
   eyeball) · R4 (build-free vs build-resolved divergence) ·
   R5 (thesis not validated end-to-end) · R6 (personas framing
   acknowledged as untested).

2. **Decisions 21–25 codified** in [decisionlog.md](../decisionlog.md).
   - **21** Consumer model: 3 agent personas (spec-authoring ·
     composing · migration) + operator. Nuri is optimised for the
     agent; operator surface is a side-effect.
   - **22** Principles split: AGENTS.md = procedure for spec-authoring
     agent; `pages/principles.html` = the WHY (for composing /
     migration / operator).
   - **23** Entry pages eliminated: `pages/home.html` and
     `pages/foundations/colour.html` deleted. No prose-essay surfaces.
     README is the "what is Nuri" doc for newcomers; the docs site is
     a catalogue navigated via sidebar.
   - **24** Component pages serve all four readers. Anatomy +
     token-mapping sections double as **migration wiring spec**;
     multi-part components require machine-readable `data-*` attrs on
     these sections.
   - **25** Risk register lives at `docs/RISKS.md` and is updated per
     session.

3. **`pages/principles.html` created** — numbered principles covering
   2-layer architecture · mode×accent composition · unit rule ·
   naming/DTCG type inference · mobile-first pressed-only · variant
   naming · tier model · components consume semantic. Rescue site
   for the prose that lived on home + colour.

4. **`pages/home.html` + `pages/foundations/colour.html` deleted**.
   `index.html` now redirects to `pages/foundations/colour/primitive.html`
   (canonical foundation, most complete page). NAV in `lib/docs/shell.js`
   updated: Home entry removed; Principles linked; "Colour" group
   header converted to non-clickable section header with
   primitive/semantic/exploration as visible children.

5. **AGENTS.md skill router refactor**. Skills: Add a new component ·
   Add a new foundation page · Add a new accent / colour scale ·
   Modify tokens (primitive / semantic / component) · Add or change a
   principle · Pipeline / DTCG export (future). Hard-rules section
   reduced to citation list referencing principles + decisions.
   `<nuri-demo>` API documented.

6. **AGENTS.md + README.md audit fixes** applied (N+2 audit punch-list).

7. **Extraction completion** (partial):
   - ✓ `.nuri-demo-card*` → `lib/docs/demo/demo.css`
   - ✓ Unified `.nuri-table` widget in `shell.css` (replaces
     `.nuri-props-table` / `.nuri-parts-table` / `.nuri-token-map`),
     supports `data-table` discriminator + `data-cell` per row
   - ✓ Topbar caret SVG fixed (inline SVG, currentColor inherits in
     dark mode — [decision 15](../decisionlog.md#15-demo-toolbar-mirrors-topbar-exactly--n2))
   - **Deferred to N+3.5**: topbar controls extraction to

     `<nuri-demo>` toolbar (`demo.js`). Markup duplication exists but

8. **Deferred to N+3.5**: Pipeline thin slice for colour primitive.
