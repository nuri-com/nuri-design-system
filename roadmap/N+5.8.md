# Session N+5.8 · Cream-default neutral parameterization · `--neutral=<scale>` CLI flag

**Status**: closed (2026-05-27)
**Type**: bridge (pipeline · parameterization)

## Outcome

The Node parser at `build/parsers/semantic.js` previously hardcoded
`const DEFAULT_NEUTRAL = 'gray'` — a default that predated conscious
decision-making (leaked from the original Radix-gray-as-baseline
assumption). N+5.8 parameterizes the build's neutral scope: the
new default is **cream** (warmer baseline matching brand content
tone), and the 6 alternative scales (`gray`, `mauve`, `slate`,
`sage`, `olive`, `sand`) remain selectable via a CLI flag
`--neutral=<scale>` on `build/tokens-parser.js`. The exploration
page's web-side `data-neutral` switcher is untouched — the CLI
flag controls only what `build/tokens.ts` emits for RN consumption.

[Decision 31](../decisionlog.md#31-default-neutral-scale--cream--cli-parameter---neutral=scale--n58)
locks the cream default + the CLI surface; the lock to a single
final default arrives when the team converges (no session anchor).

Inherits the N+5.7.1 parsimony lock — the FIXED anti-goal default
in [`prompts/working-session.md`](../prompts/working-session.md)
and the per-skill cascade ([P11](../pages/principles.html#p11-parsimony) +
[decision 30](../decisionlog.md#30-primitive-parsimony--no-speculative-additions--n571))
fired automatically; no speculative additions landed. The 6
alternative-neutral scales were already speculative-reserved in
`RESERVED_COLOR_SCALES` at the N+5.7 guardrail; cream's
graduation to default and the CLI surface are the only new things.

`npm test` is 15/15; `npm run build` emits 216 colour primitives +
18 semantic × 2 accents × 2 themes (counts unchanged from N+5.7.1
close — only resolved values shifted from gray to cream on the 16
chrome + neutral-side-accent cells).

## Why N+5.8 not N+6

N+6 is reserved for Path A (Layout primitives Stack/HStack/VStack)
or Path B (Second component page Tag/IconButton) — both component-
shipping sessions consuming the now-parameterized pipeline. N+5.8
is the last bridge: pure emitter parameterization + decision lock,
no new components, no new design surface. After N+5.8 closes, N+6
opens fresh on whichever path the operator picks.

X.Y numbering: N+5.8 follows N+5.7.1 (governance lock) and N+5.7
(primitive cleanup). The `.8` rather than `.7.2` signals a distinct
thrust — N+5.7.1 was downstream of N+5.7's findings (governance
codification); N+5.8 is upstream pipeline parameterization with no
direct lineage to N+5.7's evidence.
