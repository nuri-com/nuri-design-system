# Session N+8.1 · List fix · revert gradient wash · relocate spacing to Separator · gap-free List

**Status**: closed (2026-05-30)
**Type**: fix session (reverts two N+8 over-reaches surfaced in review ·
no new component surface · one new semantic token)

## Outcome

Two [N+8](./N+8.md) decisions were walked back after review:

1. **The press wash reverts from a gradient to a flat fill.** N+8 shipped
   the pressed wash as **`chrome.bgSubtleXFade`** — a horizontal
   `linear-gradient(to right, transparent, <bg-subtle>, <bg-subtle>,
   transparent)` with a centred plateau — so a full-bleed action box could
   read as inset *without* a counter-margin. That broke web↔RN parity
   ([R1](../RISKS.md)): a flat RN `backgroundColor` cannot paint a gradient,
   and it was the lone semantic token whose RHS was a composite gradient
   rather than a single `var()`. **N+8.1 reverts it to a flat
   `chrome.bgSubtle`** made full-bleed by a **counter-margin** on the
   `.nuri-list-interactive-item__action` box (`margin-inline: calc(-1 *
   space-md)` re-inset by an equal `padding-inline`), keeping content flush
   with the full-width Separators while the wash bleeds into the container's
   padding. The `--nuri-bg-subtle-x-fade` token (light + dark) is deleted and
   the parser's composite/embedded-`var()` resolution is removed — **no
   semantic token carries a gradient RHS anymore**.

2. **`<nuri-list>` loses its `gap`; inter-row spacing moves to the
   Separator.** N+8 added a fixed `--nuri-list-gap` (= `space.xs`) to the
   List, contradicting [decision 51](../decisionlog.md#51-list--listitem--family-capstone--one-row-shape-slots-not-use-case-variants--density-owns-row-rhythm--interactive-press-overlay--skip-emit--n7)'s
   "no gap". N+8.1 removes it — `<nuri-list>` is back to a gap-free flex
   column. Inter-row breathing room now lives on
   [`<nuri-separator>`](../lib/components/separator/) via a new **`y-space`**
   prop (default `sm`, accepts `none`), a `margin-block` that keeps the line
   at exactly 1px. A separator-less list stays deliberately flush.

The semantic space scale gains a **`--nuri-space-none` (= 0)** leaf for the
`y-space="none"` flush case.

## Decisions locked

- **[Amendment 49.1](../decisionlog.md#491-amendment--n81)** · Separator
  gains ONE prop, `y-space` (margin-block over the semantic space scale ·
  default `sm` · accepts `none`). The line stays 1px; prop-driven dispatch
  (attribute selector, like Stack `gap`), so Separator **stays skip-emit**.
  RN mirrors with `marginVertical: space[ySpace]`. Adds `--nuri-space-none`.
- **[Amendment 52.1](../decisionlog.md#521-amendment--n81)** · the gradient
  wash reverts to flat `chrome.bgSubtle` + counter-margin; the
  `--nuri-bg-subtle-x-fade` token and parser composite-gradient support are
  removed; the List `gap` is removed (decision 51 holds); the EMIT table
  now reads `washPressed = chrome.bgSubtle` with no `list.gap` row.
