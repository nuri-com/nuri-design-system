# Session N+8.4 · Component-owned labels source type from the shared scale · Button · Tab · Topbar

**Status**: closed (2026-05-31)
**Type**: token consolidation + RN migration (retires per-component font
tokens · no new component surface · no pipeline/emit change · applies the
element-vs-values rule of [decision 54](../decisionlog.md#54-type-scale-emitted-as-a-directly-accessed-namespace--one-source-two-readers--n83) ·
AMENDS [decision 46](../decisionlog.md#46-compositional-chrome-shell-via-named-light-dom-wrappers--n66))

## Outcome

[Decision 54](../decisionlog.md#54-type-scale-emitted-as-a-directly-accessed-namespace--one-source-two-readers--n83)
fixed the rule: the `<nuri-typography>` element is for **author content**;
**component-owned labels style themselves** (NOT via the element) — but the
type **values** come from the **one shared emitted scale**, never duplicated
per component. N+8.3 landed that scale and migrated the `Typography`
primitive. It left three font-bearing components carrying their own font
tokens as the explicit N+8.4 follow-up.

N+8.4 consolidates all three onto the shared scale:

1. **Button** drops `--nuri-button-{lg,md,sm}-font-size` and
   `--nuri-button-font-weight`. Its label sizes itself from the scale: web
   references the `--nuri-type-*` primitives directly in `@layer rules`
   (size · line-height · tracking · em-weight); RN reads `typeStyle('mdEm')`
   (md/lg) and `typeStyle('smEm')` (sm). **The label adopts the scale's
   line-height** (md 1.29 · sm 1.33), replacing RN's former bespoke
   `fontSize × 1.2` — see the line-height decision below.

2. **Tab** drops `--nuri-tab-font-size` and `--nuri-tab-font-weight`. Web
   Tab sizes from `--nuri-type-sm-*` (sm · semibold/em); RN reads
   `typeStyle('smEm')`. This also **fixes a latent RN bug**: RN Tab had been
   borrowing `button.mdFontSize` (17px) while web Tab is 15px — now both are
   sm/15px from the one scale.

3. **Topbar** gains a default **title type** (lg · em) on its centre region.
   Web puts the type on `.nuri-topbar__center` so **bare title text inherits**
   it (no per-text wrapper — the custom element reparents all child nodes into
   centre · `topbar.js`). RN wraps centre children in a single
   `<Text style={typeStyle('lgEm')}>` (RN can't propagate text style through a
   `View`). **Topbar thus becomes font-BEARING for its title while still
   owning zero `--nuri-topbar-*` tokens** — its empty `@layer tokens` /
   skip-emit posture from [decision 46](../decisionlog.md#46-compositional-chrome-shell-via-named-light-dom-wrappers--n66)
   is unchanged. This **reverses** decision 46's "title arrives slotted as
   `<nuri-typography>`" stance (and N+8.3's "Topbar owns no font tokens · not
   in scope" note).

## Line-height decision (operator-confirmed at checkpoint)

Button's RN label previously used `lineHeight = fontSize × 1.2`; the shared
scale's md ratio is **1.29** (sm **1.33**). Both options were surfaced at the
checkpoint — align-to-scale (adopt 1.29/1.33) vs preserve-bespoke (a 1.2
override). **Operator chose align-to-scale**: "button sm → typography sm em ·
button md, lg → typography md em · these should take all the attribute defined
size lh letterspacing." The label now takes **all four attributes** (size,
line-height, letter-spacing, weight) from the scale — no override.

| Button size | before (RN)        | after (scale)         |
|-------------|--------------------|-----------------------|
| md / lg     | 17px · lh 1.2      | 17px · lh 1.29 (mdEm) |
| sm          | 15px · lh 1.2      | 15px · lh 1.33 (smEm) |

## Anti-scope (held)

- **No `<nuri-typography>` element inside Button/Tab/Topbar** — they style
  their own labels; the element stays for author content.
- **No new per-component font tokens** — values come from the shared scale
  only; the four Button + two Tab tokens are deleted, not renamed.
- **No imperative per-text wrapper in Topbar (web)** — type lives on the
  centre container; bare text inherits.
- **The type emit / scale is untouched** — N+8.4 consumes it, does not change
  it. No change to List / Separator / IconAvatar.
- **Web stays zero-build** — CSS references the primitives directly; not
  regenerated from the emit.

## Frictions

- **F-FONT-1 (per-component font-token duplication)** · **resolved.** Button +
  Tab no longer alias `--nuri-type-*` through per-component tokens. The only
  open font strand is `fontFamily` (still hard-declared RN-side · tracked in
  `docs/RISKS.md`).
- **R1 (web↔RN parity)** · *strengthened* — the latent RN Tab size bug
  (17px vs web's 15px) is fixed; all three components now draw the same
  metrics from the one scale on both readers.
- No new friction codes minted.
