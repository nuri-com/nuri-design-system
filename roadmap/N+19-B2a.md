## What shipped

### 1 · `box` — sizing props (geometry only · NO colour · 65.3 §6)
`width` · `height` · `minHeight` join `<nuri-box>`, dispatched **exactly like decision-42
`background`/`radius`**: attribute → `data-*` → `@layer rules` attribute-selector; `@layer tokens`
stays **empty** (decision 37 · no `--nuri-box-*` aliasing). The web uses the **logical** sizing
properties (`inline-size` / `block-size` / `min-block-size`) so they pair with the logical padding
already on the box (RTL / writing-mode coherent). Value vocab = the **full** semantic size scale
`--nuri-size-*` (xs..3xl) — the whole coherent leaf set is exposed (mirroring how `RADII` exposes its
scale), with a `SIZES` enum guard + `console.warn` on a bad leaf (like `BACKGROUNDS`). `box.background`
is **untouched** (its removal is U3, not here).

### 2 · `stack` — `fill` boolean → enum `grow | grow-shrink`
`fill` is now value-aware:
- **`grow`** (the default) → `flex: 1 0 auto` — today's behaviour.
- **`grow-shrink`** → `flex: 1 1 auto` + `min-inline-size: 0` — the Topbar content-pivot (B1.5 §3),
  able to shrink below its content's intrinsic width so trailing actions stay pinned.

**Decision-60 back-compat preserved**: a bare `<nuri-stack fill>` (and `fill="grow"`) still means
`grow`; the JS normalizes `null → none`, `'' | 'grow' | anything → grow`, `'grow-shrink' → grow-shrink`
(fill present ⇒ at least grows). The one existing consumer (`pages/playground/my-vault.html` · bare
`fill`) is unaffected.

### 3 · RN mirrors (typecheck-only · decision-65 boundary)
Web API mirrored 1:1 (props parity · R1):
- `box.tsx`: `width? / height? / minHeight?: SizeLeaf` → `{ width: size[w], height: size[h],
  minHeight: size[m] }`; new `SizeLeaf = keyof typeof size` in `_shared.tsx` (next to `SpaceLeaf`).
- `stack.tsx`: `fill?: boolean | 'grow' | 'grow-shrink'` (keeps the boolean) → `grow`/`true` =
  `{flexGrow:1,flexShrink:0}`, `grow-shrink` = `{flexGrow:1,flexShrink:1}`.
- **Seam noted, no knob**: the web `grow-shrink` also sets `min-inline-size:0`; RN/Yoga flex items
  already floor their min main-size at 0, so the shrink alone reproduces it (documented in both
  mirrors · the logical→physical sizing seam likewise).

## New prop vocab

| Primitive | Prop | Web (logical) | Value vocab | RN |
|---|---|---|---|---|
| box | `width` | `inline-size` | `size.{xs..3xl}` | `width: size[w]` |
| box | `height` | `block-size` | `size.{xs..3xl}` | `height: size[h]` |
| box | `minHeight` | `min-block-size` | `size.{xs..3xl}` | `minHeight: size[m]` |
| stack | `fill="grow"` | `flex: 1 0 auto` | — (back-compat default) | `{flexGrow:1, flexShrink:0}` |
| stack | `fill="grow-shrink"` | `flex: 1 1 auto` + `min-inline-size: 0` | — | `{flexGrow:1, flexShrink:1}` |

Current live consumers of the size leaves (rebuilt as B2c consumers · P11): **md/lg/xl** (Button
`minHeight`, Topbar `height`, IconAvatar `width`/`height` · B1.5 §5). `maxWidth` / `border` stay
**mapped-not-built** (decision 30).

## Constraints honored
- **No colour** — box stays geometry-only; verified in-browser that a sized box paints a transparent
  background. `box.background` (JS, CSS, `box.tsx`) left exactly as-is.
- **Decision 37** — both primitives keep an **empty `@layer tokens`** (skip-emit confirmed:
  `wrote component 'box'/'stack' (0 decls · empty @layer tokens · no per-component file emitted)`).
- **No new tokens** — reuses the existing `--nuri-size-*` semantic scale; the primitive-consumption
  guard is untripped (every `--nuri-px-*` behind the size leaves was already consumed by
  `tokens-semantic.css`).
- `pipeline/` / `build/` / descriptors / palette / typography untouched.
