## The grounding correction — the brief's "schema = scope creep / type-neutral" premise was WRONG

The brief scoped 3a as *"the 3 descriptor copies ONLY · leave `./descriptors/schema` on `build/` — touching its
export is scope creep,"* asserting *"rn already imports the fully-typed copy, so importing the source changes
nothing type-wise."* **The sweep + the rn gate refuted both.** Dropping the descriptor `.ts` copies **forces the
schema export to follow** — a TS type-identity coupling:

- The factory derives props as `NuriComponentProps<A> = { [K in keyof A]?: A[K] }`, inferring `A` from
  `Descriptor<A>` whose `Variants<A> = { [Axis in keyof A]: { [Value in A[Axis]]: PartMap } }`. Inverting that
  nested mapped type to recover `A` (e.g. `CompositionButtonAxes`) relies on TS's **homomorphic mapped-type
  reverse inference**, which only fires when the descriptor *object* and the consuming `Descriptor<A>` generic
  resolve to **ONE `schema.ts` declaration**.
- Moving the objects to `pipeline/` makes their `import type { Descriptor } from './schema'` resolve to
  `pipeline/…/schema.ts`, while `createNuriComponent`/`contract.ts` still pulled `Descriptor<A>` from
  `build/…/schema.ts`. Two declarations → inference collapses `A` to the bare `Axes` constraint → **every
  factory component's props degrade to `{ [x: string]: string | undefined }` · exactly 4 rn tsc errors** (expo
  inherits them). Confirmed both ways: schema-on-`build/` → 4 `Variants<A>`-collapse errors; schema-on-`pipeline/`
  → 0.

**So 3a's true minimal scope is "the 3 descriptor copies + the schema export pointer"** — the schema export is
repointed to the pipeline source so objects + consumers share one declaration. This is **export-only**:
`build/descriptors/schema.ts` stays EMITTED + drift-guarded, `emitSchemaTs`'s tokens-rewrite is untouched, no
`git rm`. The build schema emit retires with the tokens move in 3b as planned. (Coordinator-ratified · no new
decision · still §80.)

## Sweep (clean)

The only **`.ts`-copy consumer** was the `@nuri/rn` exports subpath (`package.json` → `contract.ts:57-59`). All
other `build/descriptors` references are the **`.js` twins** (prototype recipes · the factory · doc staging) or
prose. `@nuri/doc`'s `stage.mjs` copies `build/descriptors/` wholesale but only ever *imports* `${name}.js`, and
its staged tree is **gitignored** (untracked build output) — dropping the `.ts` copies doesn't touch the doc gate.
