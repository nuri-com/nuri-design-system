Authoring · the merged-node class layer

Palette has no custom element. The canonical form for a multi-namespace node is class + data-* attributes on one painting element (B1.5 §4.2 · the web analogue of RN's single merged <View style>): 

<div class="nuri-box nuri-palette"
     data-chrome="strong"            <!-- palette · the colour -->
     data-radius="md" data-padding="xs">  <!-- box · the geometry -->
  …
</div>

The namespaces are disjoint (decision 65.3 §6: one node = box ⊕ stack ⊕ palette with zero attribute overlap — backgroundColor → palette, never box; flexGrow/shrink → stack, never box), so the class layers co-exist on the same node without collision. The <nuri-*> custom elements stay single-namespace sugar — their inner nodes can't merge — and a <nuri-palette> element is P11-deferred until a hand-authoring consumer exists (decision 30).

Input Type Default Description
data-variant "solid" | "soft" | "ghost" | "subtle" unset (paints nothing) The accent-aware role. solid carries accent identity (bg + on-solid fg); soft/ghost are chrome-only quiet surfaces; subtle is the one fg-only role (a near-invisible glyph treatment, never a surface · decision 50). ghost's background is an explicit transparent (the complete-pair rule). outline is RESERVED — mapped, not built (decision 30).
data-chrome "canvas" | "subtle" | "strong" unset (paints nothing) The theme-only surface slot (B1.5 §4.3) — no accent, no pressed. A separate input because the subtle role name is taken. chrome="strong" ≙ the retired Box background="strong" (amendment 42.1).

At most ONE of data-variant | data-chrome per node (the authoring contract). Accent rides the existing scope mechanism — the var(--nuri-accent-*) references re-point under any [data-accent] (Tier-2 self-scope / Tier-3 <nuri-scope>); palette adds no new mechanism.

The complete-pair rule

A palette surface resolves its complete pair — background AND foreground — explicitly. No ambient fallback, no inheritance semantics, no scope sentinel, no React context (the operator-settled B2b contract). Every dispatch row paints both channels (subtle is the one fg-only role by contract); ghost declares background: transparent rather than omitting the channel. On RN — which has no colour inheritance from a View into a child Text (F-BOX-FG-1) — the resolver returns the same complete pair and the caller passes the resolved fg to each text/icon part explicitly. muted stays delivered by Typography's existing data-muted dispatch (≙ the fgMuted column · decision 53); there is no node-level muted dispatch.

Token mapping · the dispatch table

Input value → CSS channels → DTCG → CSS var. One rule per row in palette.css, both channels per rule. The same table is emitted as TokenPath data to build/palette.ts (accent×theme-GENERIC · decision 34) and asserted cell-for-cell against the recipes' CSS at build time (decision 48 · drift Guard E) — a row here that contradicts the contract fails npm run build and npm test. Palette itself has an empty @layer tokens block (decision 37 pattern): it dispatches the semantic vocabulary directly, no --nuri-palette-* aliasing.

Reserved · mapped, not built

Named in the model (65.3 §6/§9), present in types/comments only — no rules, no values, no union members until a real consumer arrives (decision 30 · P11):

    variant outline

    Joins the variant union with its first real consumer, never speculatively.

  • reserved · evidence-gated
    the border colour role

    Border colour is palette's when it lands (border geometry — width/style — is box's · 65.3 §6).

  • reserved · evidence-gated
    onSolid.muted token (solid's fgMuted cell)

    The solid row has no muted-foreground cell — the token doesn't exist yet (decision 30).

  • deferred · B2c
    pressed dispatch (:active bg swaps)

    Gated on the interactive flag (B2c). pressedBg ships as data in build/palette.ts only; the recipes' own CSS handles their pressed states today.

  • P11-deferred
    <nuri-palette> element sugar

    The class layer is the canonical form (merged-node model · B1.5 §4.2). An element wrapper is P11-deferred until a hand-authoring consumer exists (decision 30) — today's consumers (tabs.js, the docs cells) author the class layer directly.

  • retired slotless · N+19 U3
    the old Box background="accent-subtle"

    Dropped with the Box prop (amendment 42.1) and deliberately given no palette slot — its only consumer was a demo cell (P11). The accent.bgSubtle tokens stay in the semantic set + the emitted runtime sets (the same held posture as their -pressed twin); a palette role for them returns only with a real consumer.
