# Prompts

`<!-- FIXED -->` and `<!-- VARIABLE FILL -->` sections — fill
the variables before pasting into the agent prompt.

| Template | Use when |
|---|---|

| [working-session.md](./working-session.md) | spawning a working agent for one session |
| [closeout-audit.md](./closeout-audit.md) | spawning a general-purpose audit subagent at session close |
| [migration-test.md](./migration-test.md) | spawning a fresh agent for a new web↔RN translation pair |
