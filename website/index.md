# Nuri

Generated component documentation. Each component page is **build output** —
rendered from the frozen descriptor (`@nuri/spec`) on every build by
`pipeline/parsers/docs.js`, so the docs **cannot drift** from the spec the way
the old hand-written pages did (the generation thesis · decision 66).

The live `<nuri-button>` in each **Example** is the build-free `<nuri-demo>`
widget (decision 10): one `<template>` → live preview + code, from a single
source.
