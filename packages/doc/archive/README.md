# Archive — the frozen hand-written doc pages

**Frozen. Not built. Not in the Jekyll nav.** These are the pre-A4 hand-written
reference pages, quarantined here at **N+42 · A4** (the `@nuri/doc` carve · the
`my-vault` pattern from N+36) when the doc site flipped to **generated** pages.

They are the **regen spec** for the follow-on slices:

- `components/*.html` (12) — the hand component + primitive + axis pages → the
  source material for the **axis** doc emitter (**A4b**) and the long-tail
  component descriptors (convergence phase 6).
- `foundations/**` — the colour / dimension / typography token pages → the source
  material for the **token (Foundations)** doc emitter (**A4c**).
- `principles.html` · `implementation-guide.html` — the prose docs (WHY / HOW).

Each rebuilds **as a generated page** on demand, one at a time — "everything is a
composition the generator can emit." Their asset links are **stale by design**
(the runtime moved to `@nuri/prototype` at A3; these are never served), so they
render only as frozen source, not live pages.

> Active set (decision §64 · the convergence coherence line): the live docs are
> the **generated** pages under `../generated/` — currently the 3 descriptor
> components (button · icon-avatar · topbar). See `roadmap/convergence.md` §4.
