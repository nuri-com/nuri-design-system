# Nuri

Generated design-system documentation. Component API pages are **build output** —
rendered from the RN public prop types on every build by `@nuri/doc`'s doc-gen
(`pipeline/build.js`), so the docs **cannot drift** from the production consumer
surface. Axes and foundations are generated from their source data in the same
pipeline.

The docs are organized in **three sections matching the cascade**:

- **[Foundations](foundations.html)** — the token vocabulary (colour · dimension ·
  typography). _Generated docs at A4c._
- **[Axes](axes.html)** — the 5 namespace axes (stack · box · palette · interactive ·
  typography). _Generated docs at A4b._
- **[Components](components.html)** — current component API surfaces:
  - [Button](generated/components/button.html)
  - [Icon Button](generated/components/icon-button.html)
  - [Icon Avatar](generated/components/icon-avatar.html)
  - [Tab Bar](generated/components/tab-bar.html)
  - [Tab Bar Item](generated/components/tab-bar-item.html)
  - [Topbar](generated/components/topbar.html)
  - [Stack](generated/components/stack.html)
  - [View](generated/components/view.html)
  - [Typography](generated/components/typography.html)
  - [Icon](generated/components/icon.html)
