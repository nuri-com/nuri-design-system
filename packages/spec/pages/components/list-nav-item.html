Default

API

<nuri-nav-item> is a closed scalar recipe (decision 64): it is configured by scalar attributes only — no slots, no layout knobs. It builds its internal structure by cloning a native <template> (NOT lit-html / JSX / imperative DOM · decision 52) and maps those attributes onto the composed primitives. The trailing caret is always present; a leading <nuri-icon-avatar> appears only when icon is set. For arbitrary leading or rich content, drop to the <nuri-list-item> primitive and compose directly (the escalation rule · decision 64).

PropTypeDefaultDescription
text string required The row label. Drives a composed <nuri-typography size="md" emphasis> inside the content pivot (decision 53 · md em-weight). The trailing caret is auto-filled — the author never writes it.
icon IconName — Optional. When set, mints a leading <nuri-icon-avatar name=…> positional sibling before the content pivot.
variant "solid" | "soft" | "ghost" | "subtle" soft Forwarded to the leading IconAvatar. No-op without icon.
accent Accent inherited Forwarded to the leading IconAvatar (Tier-2 self-scope). No-op without icon.
onpress handler required Forwarded to the composed interactive wrapper, which fires a bubbling press on click / Enter / Space. Nav-agnostic — routing is the author's handler.

Recipe, not variant

The disclosure pattern could have been a variant="nav" on <nuri-list-item> — but that path swells one component with use-case branches. A recipe instead NAMES the composition, takes scalar props, and leaves the primitives single-purpose (decision 52 · 64). NavItem expands to: 

<nuri-nav-item text="Activate card" onpress="goTo('/card')"></nuri-nav-item>

  →

<nuri-list-interactive-item onpress="goTo('/card')">
  <nuri-list-item>
    <nuri-list-item-content>
      <nuri-typography size="md" emphasis>Activate card</nuri-typography>
    </nuri-list-item-content>
    <nuri-icon class="nuri-nav-item__caret" name="caret-right" size="md"></nuri-icon>
  </nuri-list-item>
</nuri-list-interactive-item>

The label composes the <nuri-typography> primitive inside the content pivot (decision 53 · the single text-style owner) — never a hand-applied --nuri-type-* block. The caret is a positional trailing sibling muted with no muted prop on Icon (decision 38): the caret sets color: var(--nuri-border-strong), and <nuri-icon> paints in currentColor, so the caret reads muted by inheritance — the same trick IconAvatar's subtle variant uses.

Live demos

Press fires a bubbling press event (wired here to a console log to show the nav-agnostic contract); on press the row fills with a flat bg-subtle wash. Row height is the parent List's density — a List feature, not a NavItem one.

Token mapping

NavItem is skip-emit — it has no @layer tokens block and ships no build/components/nav-item.ts. Every value it renders is already a component token on the primitive it composes (List · Base token mapping). The only CSS the recipe adds is the muted-caret colour and the display: contents host collapse:

Part / state CSS property DTCG CSS var Reference
caret .nuri-nav-item__caret color chrome.border-strong — var(--nuri-border-strong) · positional trailing sibling · muted via currentColor (decision 38)
label font-weight type.md-em-weight — composed <nuri-typography size="md" emphasis> in the content pivot · single text-style owner (decision 53)

Behavioural delta · web ↔ RN

NavItem is a scalar recipe (props 1:1); it introduces no new behaviour, so its budget is inherited from the composed InteractiveListItem (RISKS R1). The auto-filled caret and the leading IconAvatar are decorative (aria-hidden / F-DECORATIVE-1), so they add no a11y surface of their own.

Friction Surface Web React Native Resolution
F-LISTITEM-ROLE-1 listitem role Composed <nuri-list-interactive-item> carries role="listitem" + an inner role="button". Collapses to a single Pressable accessibilityRole="button" — RN has no listitem peer. Inherited from InteractiveListItem (RISKS R1). Honest platform gap; props 1:1.
F-FOCUS-1 focus-visible The composed action box's :focus-visible ring. No DOM focus model; the Pressable a11y role substitutes, ring absent. Ring web-only by design; inherited from InteractiveListItem.
